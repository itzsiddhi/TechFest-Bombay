* 👁️ **Enhanced Vision:** 360° threat detection with infrared and quantum-spectrum analysis.

## 🧬 Tech Stack

* **Logic Engine:** Native JavaScript (`script.js`) executing an interactive HTML5 Canvas neural particle network.
